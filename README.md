# Poke Motion — Poke Achadinhos do Edu

Tutorial vertical 1080x1920 em Remotion, com narração PT-BR e legendas destacadas por palavra.

## Renderizar na nuvem
Abra **Actions > Render Poke Motion > Run workflow**. Ao finalizar, baixe o artefato **poke-achadinhos-mp4**.

O workflow instala npm, Python, ffmpeg, gera narração com Edge TTS e renderiza o vídeo.

**Importante:** a interface da Liga Pokémon é uma representação ilustrativa; nenhuma captura real do site é inventada.
